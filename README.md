<div align="center">

> *My biggest project — built entirely from scratch, step by step.*

</div>

<table>

<td width="60%">

### ✦ [Vishaknotes](https://github.com/vishaldeshmukh34/Vishaknotes) — Full Stack Notes App

A **production-grade notes application** with:

- 🔐 **JWT Authentication** — users only see their own notes
- 🌙 **Dark / Light Mode** — 2 completely different design identities
- 🎨 **16 Card Color Themes** — 8 dark + 8 light palettes
- 📌 **Pin System** — pinned notes float to the top automatically
- 🔍 **Real-time Search** — instant filtering, no API calls
- 📱 **Mobile Responsive** — bottom nav + FAB button
- ⊞ **Grid & List View** — toggle between layouts
- 👤 **Profile Page** — avatar upload + stats

</td>
